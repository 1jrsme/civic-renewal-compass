      Download map and public data

      The PNG captures the current map view and provider attribution. CSV and GeoJSON contain only currently visible features from selected, loaded map layers and visible session points; unchecked, unloaded, pending reports, and weather cards are excluded. Downloads are created on this device.

      Select and load a map data layer to enable CSV and GeoJSON downloads.

      Provider downloads for offline use

      • USGS The National Map Downloader — choose an area for official topographic maps, imagery, elevation, and other downloadable products.
      • OpenStreetMap U.S. regional extracts — select a state or area and download OSM data in formats such as PBF or GeoPackage for offline mapping software.
      • EPA cleanup-site sample (CSV) — provider download matching the app’s limited 1,000-record sample.
      • Esri World Imagery service details — the live satellite basemap is a streaming service, not a bulk offline imagery download.
      • OpenTopoMap source and usage information — terrain tiles are streamed; underlying OSM and elevation data can be obtained from their respective providers above.

      The Atlas does not bulk-download or package map tiles: public tile services may prohibit prefetching or offline tile copies. Use each provider’s official area-download products and follow its license, attribution, and usage terms.
